# oeapp.de

Mini-Demo-Webseite im Terminal-Look. Rein statisch (HTML/CSS/JS, kein PHP),
gehostet über **GitHub Pages**.

- `index.html` – die komplette Seite (Zitate, Log, Anzeigen laufen im Browser)
- `fonts/` – IBM Plex Mono, lokal eingebunden (keine externen Requests)

Änderungen: Datei bearbeiten, committen, nach `main` pushen — GitHub Pages
veröffentlicht automatisch nach ca. einer Minute.
